## О проекте

В этом репозитории собраны лабораторные работы, выполненные в рамках курса **Ассемблера (NASM, x86-64)**. Работы охватывают широкий спектр тем - от базовой целочисленной арифметики до взаимодействия с кодом на языке C.

---

## Темы работ

| № | Тема | Описание |
|:-:|:-----|:---------|
| 1️ | **Целочисленная арифметика** | Операции над целыми числами |
| 2️ | **Арифметика с плавающей точкой** | Вычисления с числами с плавающей запятой |
| 3️ | **Сортировка матрицы (Шелл)** | Сортировка прямоугольной матрицы методом Шелла |
| 4️ | **Обработка строк** | Работа со строковыми данными |
| 5️ | **Работа с файлами** | Чтение и запись файлов средствами ассемблера |
| 6️ | **Вызов функций C** | Интеграция ассемблерного кода с функциями языка C |

---

## Требования

- **Ассемблер:** [NASM](https://www.nasm.us/)
- **Архитектура:** x86-64
- **Компилятор C (для соответствующих работ):** `gcc` / `clang`
- **Линковщик:** `ld` или `gcc`

---

## Сборка и запуск

Пример сборки типичной программы:

```bash
# Ассемблирование
nasm -f elf64 program.asm -o program.o

# Линковка
ld program.o -o program

# Запуск
./program
